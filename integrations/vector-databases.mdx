AgentHeaven connects to vector databases through [LlamaIndex](https://www.llamaindex.ai/), supporting multiple backends for semantic search and embedding storage.

<br/>

## LanceDB

The default local vector store — zero-config, file-based, and fast for prototyping.

```bash
pip install lancedb
```

LanceDB is used automatically when you create a `VectorKLStore` without specifying a backend.  No server process is needed — data is stored in a local directory.

<br/>

## ChromaDB

Lightweight open-source embedding database with a simple Python API.

```bash
pip install chromadb
```

```bash
ahvn cfg set vdb.backend chromadb
ahvn cfg set vdb.chromadb.host "localhost"
ahvn cfg set vdb.chromadb.port 8000
```

<br/>

## Milvus

Scalable vector database for production workloads. Supports distributed deployment and billion-scale vector search.

```bash
pip install pymilvus
```

```bash
ahvn cfg set vdb.backend milvus
ahvn cfg set vdb.milvus.uri "http://localhost:19530"
```
