title: "Integrations"
description: "Connect AgentHeaven with external systems — LLM providers, databases, vector stores, MCP clients, and more."
---

<Note>
    *Plug-and-play backends — swap any external system without changing application code.*
</Note>

AgentHeaven is designed to be backend-agnostic. Your application code references logical names (presets, providers, collection names), and the actual external system can be swapped via [Configuration](/features/configuration).
