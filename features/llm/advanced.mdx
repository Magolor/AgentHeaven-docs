## 1. Image Generation

{/* TODO: Document image generation API once stabilized */}

AgentHeaven supports image generation through providers that offer it (e.g., OpenAI's DALL-E, Google's Imagen). Configuration follows the same preset pattern:

```bash
ahvn cfg set llm.presets.image.provider openai
ahvn cfg set llm.presets.image.model dall-e-3
```

<br/>

## 2. Include Finetuning

{/* TODO: Document include-based finetuning approach */}

The `include` finetuning approach augments prompts with cached experience and examples at inference time, without modifying model weights. This is the same pattern used in the [IMDb Sentiment Analysis](/blog/imdb-sentiment-analysis) blog post — inject relevant prior outputs to improve accuracy.

<br/>

## 3. Custom Backends

Any provider supported by LiteLLM can be configured. For providers not in the default list:

```bash
ahvn cfg set llm.providers.custom_name.backend <litellm_prefix>
ahvn cfg set llm.providers.custom_name.api_base "https://your-endpoint/v1"
ahvn cfg set llm.providers.custom_name.api_key "..."
```

See [LiteLLM Providers](https://docs.litellm.ai/docs/providers/) for the full list of supported backends.
